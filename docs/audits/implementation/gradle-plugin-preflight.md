# Проверка конфигурации Gradle после слияния PR 68

Работа продолжается в `fix/audit-stage0-release-delivery-20261104`.
Основа — main `e43f4980ac1d859dcb4af6ba998042bbdf60990a`, результат
самостоятельного слияния владельцем PR 68. Дерево main совпало с деревом
предыдущего head рабочей ветки `c82228112194e46798e21a0d0c4abae2b7082222`.
Новые изменения не записываются в main и не публикуют релиз.

## Наблюдение

В [run 41932759000](https://github.com/alcovaibe/vk-music-export/actions/runs/41932759000)
задание `interface (API 35)` / job `126933603236` завершилось до компиляции
и Android-тестов: Gradle не смог разрешить маркер
`org.jetbrains.kotlin.plugin.compose:org.jetbrains.kotlin.plugin.compose.gradle.plugin:2.4.21`.
Остальные задания того же коммита разрешили зависимости. Версия опубликована
в [официальном каталоге Gradle](https://plugins.gradle.org/plugin/org.jetbrains.kotlin.plugin.compose/2.4.21).
Лог не устанавливает первопричину отказа репозитория; временный сбой — предположение.

Проверка `channel-delivery`, включая настоящий публичный JSON после слияния,
и все девять заданий updater API 29–37 прошли в этом запуске. Это не означает,
что вся общая матрица прошла: исходный отказ API 35 сохранён в истории.

## Изменение

Перед сборкой запускается `tools/gradle_preflight.py`: только Gradle `help`
со строгой проверкой зависимостей и диагностикой `--info --stacktrace`.
Предусмотрены максимум две попытки, пауза 10 секунд, на второй попытке
`--refresh-dependencies`. Шаг CI ограничен пятью минутами.

Повтор допустим только для точного отказа известного опубликованного
Compose-плагина 2.4.21, совпадающего с версией каталога, до выполнения задач.
Неизвестная версия, ошибка проверки зависимостей/подписи/checksum, отказ
авторизации/TLS, прерывание процесса или уже начавшаяся задача повтор не получают.
Постоянная ошибка остаётся красной после второй попытки. Фактические команды
компиляции, Lint, R8, unit и instrumentation не обёрнуты повтором.
Версии, lockfile и verification-metadata не меняются.

Шаг добавлен в build, interface-tests, channel-delivery и release. Для
push, меняющего только сгенерированный JSON, сборка host и preflight по-прежнему
не запускаются. Публикация релиза требует прежнего отдельного запроса.

## Проверки

Локально: `python3 -m unittest discover -s tools -p 'test_*.py'` —
126 тестов, OK, 3.091 секунды. Семь новых тестов проверяют распознавание
наблюдавшегося отказа, отказы без повтора, строгую команду, восстановление
на второй попытке и передачу кода окончательной ошибки. Это тесты с подменой
процесса Gradle, они не доказывают восстановление реального сетевого сбоя.

YAML успешно разобран, `git diff --check` прошёл. Локальная сборка Android
и тесты AVD в эту проверку не входят; их результат следует смотреть в Actions
на точном SHA новой ветки. Отдельный повтор упавшего задания main запрошен
без изменения его исходников; результат повтора не объявляется заранее.
