# Обновления приложения с 0.9.6

Кнопка с двумя стрелками находится в нижнем правом углу главного экрана (с 0.9.7). Проверка, наличие новой версии, прогресс, повтор и установка используют нижнюю Compose-панель, по примеру Bluetooth Disable. Пункт и отдельный экран обновлений из настроек удалены. Проверка при показе главного экрана выполняется раз в сутки; автоматические ошибки не открывают панель. Ручная проверка имеет паузу 5 секунд. «Позже» откладывает именно найденную версию; отмена скачивания удаляет неполный APK. Автоматическая проверка включена, прежний переключатель больше не используется.

Метаданные запрашиваются только при активном главном экране. Переход в настройки/музыку и сворачивание отменяет метаданные и убирает их временный результат. Начатое пользователем скачивание и готовый APK переживают сворачивание и пересоздание Activity; при возврате на главный экран панель доступна снова. Скачивание начинается только по кнопке. Процессный перезапуск потребует скачать APK заново.

Публичный JSON-канал docs/updates/android.json и проверка размера, SHA-256, пакета, версии, minSdk и подписи APK сохранены. Установку подтверждает Android; после разрешения установки из этого источника нужно вернуться и снова нажать «Установить». Материал доступа ВК не отправляется в GitHub. build-info.json, upgrade-check.txt, SBOM и OSV-отчёт публикуются рядом с APK начиная с 0.10.0.

RC проверяется поверх текущего stable и поддерживаемой 0.9.5 (1087) с прежней подписью. Push в main не выпускает stable. Продвижение точного APK требует ручной приёмки; после публикации и сверки открывается отдельный PR канала. Установленные приложения увидят новую версию после его слияния. До этого канал продолжает описывать прежний stable. См. [порядок выпуска](RELEASING.md).
