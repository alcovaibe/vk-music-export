## Что реализовано

- Сбор исполнителей и названий из «Моей музыки» ВК и отдельного плейлиста через разбор DOM, прокрутку страницы и раскрытие списка.
- Аналогичная выгрузка списков из Яндекс.Музыки.
- Управляемый браузер Chrome/Edge/Firefox; подключение к уже запущенному Chromium через CDP; отдельные сниппеты для ручного запуска в консоли страницы.
- Сохранение TXT формата «Исполнитель - Название», проверка формата и разбиение на части, по умолчанию по 500 строк.
- Описан перенос TXT через TuneMyMusic. Есть отдельные команды для работы с избранным Spotify через API и браузер, включая отчёты и повтор пропусков. Браузерный режим может удалять обработанные треки из Spotify-плейлиста по отдельному флагу.

## Применимость к VK Music Export

Для основной задачи владельца — скачивать реальные аудиофайлы ВК на Android и сохранять их в Music/VK Music Export с очередью и папками — этот проект не заменяет нашу реализацию: загрузки аудио в нём нет.

Может пригодиться как источник идей для будущего TXT-экспорта списков, поддержки Яндекс.Музыки и переноса списков между сервисами. Возвращение этих функций требует отдельной задачи владельца.

Сборщик ВК зависит от разметки сайта. После нескольких проходов без изменений прокрутка завершается; перед сохранением нет общего обязательного требования совпадения полученного числа треков с ожидаемым. Поэтому сохранённый TXT сам по себе не подтверждает полноту библиотеки.

Проверка выполнена по README и исходникам. Запуск с реальными аккаунтами ВК, Яндекса или Spotify не проводился. Перед использованием нужно заново проверить актуальные исходники, лицензию и работу сервисов.
