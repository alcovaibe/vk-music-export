# Имена файлов и папок · 0.9.2

Служебные номера были добавлены приложением: префикс `00001` обозначал позицию, суффикс `[owner_id]` различал записи. Теперь они остаются только в приватном учёте. Видимые имена:

- `Моя музыка/Исполнитель — Песня.mp3`
- `Плейлисты/Солнечный день/Исполнитель — Песня.mp3`
- `Альбомы/Название альбома/Исполнитель — Песня.m4a`

`ExportLayout.name` больше не добавляет номер позиции или ID. Из папок снимается только последний добавленный приложением суффикс; настоящие цифры и скобки в исходном названии сохраняются. Очистка разделителей, управляющих символов, NFC и предел UTF-8 прежние. Сортировка файлов по имени теперь алфавитная; порядок и повторения ВК остаются в задачах.

`AudioExportStore.directory` связывает прежнюю идентичность источника с обычным относительным путём. Разные источники с одинаковым очищенным названием получают `(2)`, `(3)`; сравнение учитывает регистр через Locale.ROOT. Соответствие транзакционное и сохраняется после перезапуска, очистки очереди или новой подготовки списков. В SQLite v2 добавлена только таблица directories, таблицы tasks/files/meta не меняются.

При повторяющихся названиях треков SharedAudioStore выбирает свободное имя с коротким `(2)`, `(3)` среди доступных собственных записей. MediaStore назначает окончательное уникальное имя также при конфликте с чужим файлом или гонке. Готовый файл не открывается на перезапись: запись всегда начинается с нового insert/IS_PENDING. Фактические DISPLAY_NAME и RELATIVE_PATH читаются из MediaStore перед контрольной точкой.

Существующие файлы/папки не переименовываются и не удаляются. Старые задачи содержат прежние идентификаторы папок; они продолжают читаться без изменения сериализованной схемы. Ключи задач вычисляются как прежде. Это сохраняет индекс уже скачанных треков и восстановление контрольной точки. Невыполненные задачи получают новый видимый путь, выполненные используют проверенный прежний URI. Поэтому старые и новые файлы могут оставаться в разных папках до ручного переноса владельцем.

Реальные проверки Android: одинаковые имена/повторы на MediaStore, раздельные папки и устойчивость соответствий после открытия БД заново, повторная очередь без сети, миграция схемы v1 с готовым файлом в прежнем имени и продолжение незавершённой позиции локальной копией. Проверки синтетические, без аккаунта владельца. Релизный APK проверяется поверх опубликованной 0.9.1 (1070), без удаления приложения.

Официальная модель хранения: [Android shared media](https://developer.android.com/training/data-storage/shared/media), [RELATIVE_PATH](https://developer.android.com/reference/android/provider/MediaStore.MediaColumns#RELATIVE_PATH). Доступ выполняется по content URI, а не построением абсолютного пути накопителя.
