# Удаление локальной коллекции в 0.9.5

Удалены просмотр и поиск сохранённых страниц, их сохранение из музыкального раздела, подтверждение замены и «Очистить коллекцию» в настройках. Удалены MusicViewModel, CollectionStore, CollectionMerge, модели коллекции и преобразование страницы API в коллекцию.

На главном экране остаются «Открыть мою музыку», настройки и версия. Музыкальный раздел читает библиотеку через NativeMusicViewModel и MusicApi, затем создаёт задания AudioExportRuntime/AudioExportStore. Эти компоненты не используют коллекцию. Авторизация через Chrome, зашифрованный доступ, очередь и файлы Music/VK Music Export сохраняются.

Старый filesDir/collection.json не удаляется, не читается и не переписывается. Его фикстура остаётся только для проверки обновления со старого выпуска. Это не база очереди: очередь хранится отдельно в noBackupFilesDir/audio-export.db. Автоматическая очистка пользовательских данных в этот PR не входит.

Регрессии: главный экран и настройки после пересоздания Activity, запуск с повреждённым старым файлом коллекции, прежние тесты авторизации, MediaStore, SQLite и UIDT. В наборе остаются 27 инструментальных тестов для API 36/37. Релизный install -r поверх подписанной 0.9.4 (1085) проверяет новый главный экран, хеш старого файла, публичную музыку и приостановленную очередь. Реальный аккаунт владельца в CI не используется.
