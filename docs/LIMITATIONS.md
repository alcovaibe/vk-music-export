# Ограничения 0.9.2

- Android 16/API 36+. Реальный телефон владельца — Samsung/Android 17; CI выполняется на Android 16.
- Протокол музыкального доступа ВК внутренний. Выданный результат принимается только после музыкальной проверки. Истёкший доступ требует повторного подключения; refresh не реализован.
- Chrome нужен для подтверждения подключения, его профиль не копируется. Обычный запуск сайта и браузерный сбор удалены.
- Пагинация проверяет количество и прогресс. Неизменность порядка при неизменном счётчике ВК не гарантируется. Недостающие источники и ошибки отражаются как пропуски.
- Подготовку списков дождаться на экране. Аудио затем работает в UIDT-задаче; система может её остановить. После перезапуска нажать продолжение, текущий незавершённый трек начинается заново.
- Один трек: до 100 МиБ и 10 минут, поддерживаемое подмножество HLS VOD, MP3 или AAC→M4A без перекодирования. Неподдерживаемый формат даёт явную ошибку.
- Скопированный в разные папки трек занимает место несколько раз. Альбомы из библиотеки содержат только сохранённые в ней треки. Неизвестный тип подборки сохраняется в «Плейлисты»; вручную можно выбрать «Альбомы».
- Коллекция содержит только явно сохранённые страницы и прежние списки; очередь не заполняет её автоматически. TXT/CSV/JSON/ZIP-выгрузка коллекции удалена по решению владельца.
- Старый внутренний аудиоархив удаляется при обновлении. Новая музыка в Music/VK Music Export, очередь, доступы, коллекция и диагностика сохраняются. [Точный список путей](CLEANUP-0.9.1.md).
- Реальная массовая загрузка 4449 треков пока не подтверждена. Один реальный MP3 и сохранение в новом каталоге подтверждены владельцем; синтетические тесты не заменяют проверку его аккаунта.

- Чистые имена 0.9.2 применяются к новым файлам, включая продолженные задачи старой очереди. Прежние файлы автоматически не переименовываются. После удаления номеров сортировка файлов по имени не воспроизводит порядок ВК. Дубли названий получают короткий суффикс. [Имена](NAMES-0.9.2.md).
