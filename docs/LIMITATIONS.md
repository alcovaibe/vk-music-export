# Ограничения версии 0.2.0

- Авторизация ВК в WebView и сбор на аккаунте владельца требуют проверки на телефоне.
- Парсер поддерживает известные варианты DOM музыкальных страниц; современная/региональная разметка может отличаться.
- Автоматический обход плейлистов выполняется только при распознанном отдельном контейнере плейлистов. Рекомендации вне него не добавляются.
- Наличие частичного результата не подтверждает полноту коллекции. Даже совпадение счётчика не доказывает неизменность списка во время сбора.
- Пропущенные строки, неизвестные позиции при виртуализации, отсутствие счётчика или неподтверждённый конец списка отображаются в отчёте.
- Дубликаты без идентификатора ВК автоматически не объединяются. Это сохраняет разные записи с совпадающими названиями.
- Удалённые или недоступные ВК названия восстановить из отсутствующих данных нельзя.
- Сбор работает в открытом приложении. Сохранение результата есть; продолжение с точной последней позиции и Room пока не реализованы.
- Каждый источник ограничен 2500 порциями; поиск плейлистов — 400 порциями, обработка — 1000 плейлистами. Достижение лимита не подтверждает полноту.
- Внешние ссылки и сторонние схемы переходов автоматически не открываются. Если вход требует неподдерживаемого перехода, необходима доработка по результату диагностики.
- CSV содержит статусы источников в строках треков; для отчёта о пустых/ошибочных плейлистах используйте JSON или ZIP.
- Вся коллекция при новом запуске перечитывается с начала. Перед новым сбором можно экспортировать имеющийся результат.
- Постоянная подпись release-сборок, проверка на нескольких версиях Android и тесты на реальной коллекции остаются следующими этапами.
