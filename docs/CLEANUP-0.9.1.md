# Удаление прежних компонентов · 0.9.1

Владелец разрешил удалить неиспользуемые браузерные функции, старый внутренний аудиоархив и вкладку экспорта списков. Новые загрузки и подключение ВК должны продолжить работу.

Удалены обычный запуск vk.ru, CollectorGuide/CollectorBookmark, JS и URL закладок/диагностики разметки, ChromeImport и его внешние форматы, Exporter/ExportFormat и экран TXT/CSV/JSON/ZIP, прежние NativeFiles/SavedAudio и аудио-FileProvider. Удалены только соответствующие снятым функциям тесты и Node/Terser-сборка. Рабочие проверки API, авторизации/кода, Media3/MediaCodec, публичного хранилища и очереди остаются.

NativeOperationJournal сохраняет владение и восстановление нативных операций по прежнему пути `noBackupFilesDir/native-music-operation.json`. CollectionMerge сохраняет подтверждённую страницу и другие списки без браузерного импортёра. ChromeDiagnostics сохраняет версию Chrome без запуска сайта. DeviceAuth/Custom Tabs и библиотека androidx.browser остаются для реального подключения.

## Разрешённая область очистки на устройстве

LegacyAudioCleanup на IO удаляет ровно следующие старые пути:

- `filesDir/native-audio/` — прежние внутренние MP3/M4A;
- `filesDir/native-audio-index.json`, его `.bak` и `.new`;
- `cacheDir/native-audio-transfer/` — прежние временные загрузки.

Эти пути не содержат новую очередь или публичные файлы Music. Обход `Files.walkFileTree` не следует по символическим ссылкам: удаляется ссылка, а не её цель. После полного успеха AtomicFile записывает `noBackupFilesDir/legacy-audio-cleanup-v1`. При прерывании или ошибке маркер не ставится, следующий запуск повторяет только эту же ограниченную очистку. В лог попадают только число удалённых файлов/фиксированная ошибка. Отказ очистки не блокирует вход.

Очистка не посещает `Music/VK Music Export/`, `noBackupFilesDir/audio-export.db` и его WAL, `cacheDir/audio-export-transfer/`, `collection.json`, конверты доступа, журналы диагностики и файлы обновлятора. Имена старого и нового временного каталога различаются. Коллекция остаётся схемы 1, очередь — схемы 1. Системные разрешения UIDT, уведомления и Chrome queries сохранены; удалён только provider прежнего внутреннего аудиоархива.

## Проверка границ

Android-тест очистки создаёт старые файлы и одновременно настоящую SQLite-очередь, опубликованную MediaStore-запись, текущий временный файл, коллекцию, служебный журнал и байтовые фикстуры конвертов. После очистки проверяются удаление только старых путей, сохранность остальных данных и повторный безопасный запуск. Отдельно проверяется ссылка из старого каталога в новый временный каталог.

Тесты сохранения нативной страницы проверяют отмену без записи и подтверждение замены только одного списка. Прежние тесты авторизации и ввода кода продолжают проверять сохранение старого доступа при отказе.

Релизный `install -r` поверх опубликованной 0.9.0 (1067) на одноразовом API 36 AVD проверяет прежний сертификат и пакет, отображение/хэш коллекции, сохранность публичного файла Music и приостановленной очереди v1, очистку старого архива и диагностический перезапуск. Фикстуры не используют реальный аккаунт. Скачивание реальной музыки после обновления проверяет владелец.
