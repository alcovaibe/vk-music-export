## Граница автоматической проверки

CI и синтетические регрессии не подтверждают реальный вход, длительный фон, массовый экспорт или удаление на сервере ВК.
Результаты таких проверок в этой ветке не выдумываются. Stable допускается только после заполнения и проверки протокола приёмки для конкретных исходников.
Правила защиты ветки в конфигурации PR необходимо применить в настройках GitHub; сам файл не меняет административные настройки.

Новый подписанный upgrade с обеих контрольных версий подготовлен в RC workflow. В PR нет доступа к ключу подписи: его успешный фактический прогон до выпуска остаётся обязательным. MIT в этом PR — предлагаемая лицензия, которую должен утвердить владелец при ревью.

Guava обновлена до исправленных 33.7.2-android (приложение/тесты) и 33.7.2-jre (lint tool), GHSA-xxph-c9ww-hj94. SBOM/SCA охватывает разрешённые classpath приложения/тестов и androidLintTool; Gradle plugins дополнительно закреплены версиями и checksum metadata.
