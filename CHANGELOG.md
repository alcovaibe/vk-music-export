# Изменения

## [0.11.5]

- Добавлен раздел «Друзья»: поиск, музыкальные профили с коротким именем ВК, отдельные вкладки треков, плейлистов и альбомов. Альбомы не включаются во вкладку плейлистов.
- Музыку друзей и отдельные треки можно скачивать через общую фоновую очередь. Перед скачиванием проверяется актуальный состав; сохраняются исходные позиции и ID записей.
- Ошибки доступа к музыке друга показываются отдельно и не объявляют всё подключение ВК недействительным. Смена аккаунта сбрасывает устаревшие данные профиля.
- Расширен разбор форматов музыкальных подписок на исполнителей и переходов «Показать всех». Добавлена диагностика структуры каталога без личных значений. Успешная загрузка подписок на реальном аккаунте пользователя ещё не подтверждена.
- Сохранены открытие общей очереди после пересоздания экрана и работа фоновых загрузок. Новые профили и плейлисты открываются с начала страницы.

## [0.11.4]

- Обновление названий и пометок, добавление обложек и проверка сохранённых файлов продолжаются в фоне. Уведомление показывает прогресс, позволяет поставить обработку на паузу и вернуться к ней.
- Очередь, позиция и результаты сохраняются для продолжения после остановки процесса. Ручной выбор записей и подтверждения остаются в существующем интерфейсе.
- Ошибка загрузки исполнителей показывает метод и код API ВК, HTTP-статус, сетевой сбой или проблему разбора каталога. Отсутствие раздела подписок не объявляется подтверждённым отказом ВК.
- Из меню трёх точек убраны повторяющиеся пункты «Доступ к музыке» и «Инструменты сохранённых файлов».

## [0.11.3]

- Исправлена навигация по музыкальным подпискам исполнителей: полное чтение «Моей музыки», вкладки и кнопки «Показать всех», повторный запрос каталога текущего пользователя.
- Исправлено принятие нажатия на удаление дубликата при завершении фоновой задачи. Подтверждение работает после проверенного автопродления той же сессии ВК.
- Поиск дубликатов проверяет уже скачанные приложением файлы без повторной загрузки. Завершённые проверки повторно используются после перезапуска, перестановки треков и изменения альбомной группировки; данные проверок 0.11.2 сохраняются.
- В меню трёх точек добавлен экран «О приложении» с версией, лицензией и сведениями о данных и доступе. Версия убрана с остальных страниц.
- Для «Друзей» установлена присланная иконка; переход и логика очереди сохранены.

## [0.11.2]

- Вместо надписи VK используется логотип с прозрачными углами. Иконка приложения — бирюзово-фиолетовая нота со стрелкой и градиентом на чёрном фоне без внешнего свечения.
- Нижний пункт «Загрузки» переименован в «Друзья»; переход и работа очереди сохранены.

- Исправлены чтение музыкальных подписок ВК и переходы раздела исполнителей. Загрузка ограничена по времени, частичный результат остаётся доступным.
- Обновления приложения открываются нижним диалогом из меню; отдельная кнопка убрана. Версия приложения сохранена.
- Для недоступных исходных ID при проверке названий добавлен ручной поиск или ссылка на запись ВК с просмотром и подтверждением названия/версии. Выбор сохраняется для следующих проверок файла; звук, обложка и исходный ID сохраняются.

## [0.11.0]

- Музыкальный раздел переработан по выбранному светлому референсу: карточки категорий, пометки версий и нижние разделы «Библиотека», «Сохранённое», «Загрузки».
- Все дополнительные инструменты сохранены и распределены по библиотеке, сохранённым файлам и очереди.
- «Мои исполнители» показывает музыкальные подписки из каталога ВК, треки, альбомы и синглы. Вход только из списка подписок; доступность раздела зависит от ВК.
- Сохранённое показывает весь локальный индекс, включая музыку, удалённую из ВК. Обложки видимых строк загружаются отдельно, временные адреса остаются в памяти.
- Подписанный RC можно явно собрать из выбранной ветки репозитория без слияния PR.


- Проверка названий продолжает работу после проверенного автообновления токена ВК; ручной вход и смена аккаунта останавливают текущий проход. Сессия чтения сохраняется при любом числе продлений, в том числе для короткоживущих токенов.
- Срок упреждающего обновления учитывает время жизни токена. После временного сетевого сбоя повтор обновления назначается до известного истечения, без частых повторов в цикле.
- Прогресс проверки названий сохраняется после каждого файла отдельно для аккаунта. После остановки, потери сети, повторного входа или перезапуска приложения кнопка «Продолжить» возвращает к необработанной записи; готовые позиции повторно не запрашиваются. Ошибка доступа не записывается как ошибка каждого оставшегося трека.

## [0.10.5]

- Пометки версий из `subtitle` ВК (cover, sped up, slowed, remix и другие) сохраняются в названиях треков, именах файлов, тегах MP3/M4A и M3U8. Свежие метаданные используются и при старой очереди без пометки.
- Действие «Обновить названия и пометки» получает метаданные по сохранённым ID, независимо от наличия песни в «Моей музыке». Обновляет старые файлы и все их связи, включая M3U8 прежних очередей, без повторной загрузки или перекодирования звука и без удаления обложек.
- Обработка различает исправленные, актуальные, недоступные записи, пропуски и ошибки. Не угадывает версии по `(2)`/`(3)`, похожим названиям или длительности; не изменяет файлы с нарушенной целостностью, неподтверждённые локальные замены и сохранения другого аккаунта.
- Изменение тегов и имени защищено резервной копией и журналом восстановления. Номера при совпадении имён остаются только для реальных конфликтов файлов; для длинных имён резервируется место под пометку версии.

## [0.10.4]

- Удалена кнопка скачиваний под VK Music на главном экране, музыкальный экран переименован в «Доступ к музыке».
- Типы определяются по серверному фильтру альбомов ВК; ручной выбор и старые пользовательские назначения исключены из просмотра и планирования.
- Полностью скачанные подборки скрываются только после сверки актуального состава, аккаунта, целостности файлов и M3U8; массовая очередь их пропускает.
- Обновление каталога очищает выбранный источник и устаревшие данные даже при ошибке. Перед открытием и планированием подборка сверяется с текущим каталогом ВК. Удалённые и явно несохранённые внешние источники не добавляются из истории скачиваний.
- Исправлено ложное сообщение о неполном каталоге при повторяющихся позициях между страницами; реальный недобор и повтор одной страницы по-прежнему обнаруживаются.

- Убраны поясняющие заголовки главного экрана и блока ручного доступа, а также кнопка изменения сохранённого доступа ВК.
- «Данные и доступ» и «Лицензия» перенесены в меню трёх точек главного экрана и открываются снизу; с экрана прямого доступа ссылки убраны.
- Треки, плейлисты и альбомы отображаются в едином прокручиваемом списке. Все страницы ВК загружаются автоматически, кнопки перехода по 100 позиций удалены. Длинные списки используют ленивое создание строк.

## [0.10.3]

- Одна проверенная копия трека с тем же ID ВК используется в альбомах, плейлистах, «Моей музыке» и повторяющихся позициях. Дополнительные подборки получают ссылки M3U8 без копирования аудио и повторного запроса ВК.
- Перемещение, восстановление и изменение обложки обновляют все связи с общим файлом одной транзакцией. Удаление одной записи из учёта сохраняет файл и остальные связи.
- Сохранённый журнал переносов обновляет относительные пути в прежних M3U8, в том числе после смены очереди. Изменённый пользователем плейлист не перезаписывается; нерешённый перенос остаётся в журнале и показывается как проблема.
- История последних файлов и проверка сохранённого не размножаются из-за нескольких ссылок. Очистка истории остаётся в силе при повторном использовании файла.
- Ошибки сохраняют измеренную и ожидаемую длительность, длительность HLS, точную причину недоступности или статус HTTP медиасервера. Подробности видны в очереди и JSON-отчёте и сохраняются после перезапуска; URL и ответы серверов в них не записываются.
- Выбранная вручную отличающаяся копия помечается локальной заменой. Совместное использование и перемещение не превращают её в доказательство сохранённого оригинала для удаления песни из ВК.
- Уже существующие лишние файлы не удаляются. Файлы других приложений и записи с разными ID не объединяются по одному названию; неподтверждённая длительность остаётся ошибкой.

## [0.10.2]

- Снят лимит 100 МиБ на аудиозапись и общий десятиминутный срок загрузки. Длинные MP3/AAC обрабатываются потоком с проверкой свободного места; тайм-аут неактивного сетевого соединения и отмена сохранены.
- Повтор очереди проверяет готовые файлы локально и загружает только ошибки и отсутствующие/изменённые копии. Повторный выбор того же плейлиста также использует сохранённые файлы.
- Перемещённые файлы автоматически связываются с учётом по размеру и SHA-256. Известная копия из альбома, перенесённая с заменой в папку плейлиста, переиспользуется без скачивания. Неоднозначные совпадения и файлы, к которым Android не дал доступ, требуют ручной проверки.
- Сохранены проверки полноты аудио и длительности: неполный файл не объявляется готовым. Предел конечного HLS-списка увеличен до 20 000 сегментов.

## [0.10.1]

- Недоступные треки и ошибки HTTP отдельных аудиофайлов больше не останавливают скачивание следующих записей плейлиста. Истёкшая ссылка обновляется ограниченное число раз; пропуски сохраняются в итоговом отчёте.
- Отказ доступа к отдельной записи отделён от отказа токена аккаунта. Потеря сети, нехватка места и настоящий отказ входа сохраняют очередь для продолжения.
- Перестановки, добавления и удаления других записей библиотеки не сбрасывают готовые проверки дубликатов. Изменившийся трек теряет только собственную проверку.
- Поиск дубликатов заканчивается одним проходом даже при изменении библиотеки: изменившиеся записи исключаются из предложений удаления, автоматического повторного скачивания всей библиотеки нет.
- Удаление каждого дубликата по-прежнему требует отдельного подтверждения и свежей проверки обеих аудиозаписей.

## [0.10.0] — кандидат публичного релиза

- Старый внутренний архив сохраняется и переносится в общую музыку с проверкой размера и SHA-256. Повреждённые записи можно сохранить отдельно.
- Очередь привязана к аккаунту ВК; другая учётная запись не может продолжить её без проверки. Новые данные входа заменяют старые после успешной проверки.
- Перестановка треков и переименование плейлиста не создают повторные копии. Повторяющиеся композиции остаются отдельными позициями.
- Полнота HLS проверяется также по длительности из каталога. Сравнение M4A учитывает конфигурацию декодера и временную шкалу.
- M4A получает текстовые теги, подборки — переносимый M3U8 с порядком и отметкой неполной выгрузки.
- Все ошибки очереди доступны постранично, сохраняются ошибки источников, добавлены адресный повтор и отдельный отчёт результата выгрузки.
- Доступен диагностический журнал предыдущего запуска; из кэша поиска дубликатов удалено ненужное хранение аудио.
- Выпуск stable отделён от push в main: сначала RC, затем приёмка точного APK. Добавлены фиксация зависимостей, SBOM, SCA и публичные доказательства сборки.
- Транзитивная Guava обновлена до 33.7.2-android для исправления GHSA-xxph-c9ww-hj94.
- При переносе старого архива и восстановлении незавершённой записи учитывается окончательное имя, выбранное Android при совпадении файлов. Исходные файлы сохраняются.

Реальный вход/продление ВК, массовая выгрузка и длительная фоновая работа требуют ручной приёмки RC. До её заполнения stable заблокирован.
