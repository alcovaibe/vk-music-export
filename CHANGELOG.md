# Изменения

## [0.10.3]

- Одна проверенная копия трека с тем же ID ВК используется в альбомах, плейлистах, «Моей музыке» и повторяющихся позициях. Дополнительные подборки получают ссылки M3U8 без копирования аудио и повторного запроса ВК.
- Перемещение, восстановление и изменение обложки обновляют все связи с общим файлом одной транзакцией. Удаление одной записи из учёта сохраняет файл и остальные связи.
- История последних файлов и проверка сохранённого не размножаются из-за нескольких ссылок. Очистка истории остаётся в силе при повторном использовании файла.
- Ошибки сохраняют измеренную и ожидаемую длительность, длительность HLS, точную причину недоступности или статус HTTP медиасервера. Подробности видны в очереди и JSON-отчёте и сохраняются после перезапуска; URL и ответы серверов в них не записываются.
- Уже существующие лишние файлы не удаляются. Файлы других приложений и записи с разными ID не объединяются по одному названию; неподтверждённая длительность остаётся ошибкой.

## [0.10.2]

- Снят лимит 100 МиБ на аудиозапись и общий десятиминутный срок загрузки. Длинные MP3/AAC обрабатываются потоком с проверкой свободного места; тайм-аут неактивного сетевого соединения и отмена сохранены.
- Повтор очереди проверяет готовые файлы локально и загружает только ошибки и отсутствующие/изменённые копии. Повторный выбор того же плейлиста также использует сохранённые файлы.
- Перемещённые файлы автоматически связываются с учётом по размеру и SHA-256. Известная копия из альбома, перенесённая с заменой в папку плейлиста, переиспользуется без скачивания. Неоднозначные совпадения и файлы, к которым Android не дал доступ, требуют ручной проверки.
- Сохранены проверки полноты аудио и длительности: неполный файл не объявляется готовым. Предел конечного HLS-списка увеличен до 20 000 сегментов.

## [0.10.1]

- Недоступные треки и ошибки HTTP отдельных аудиофайлов больше не останавливают скачивание следующих записей плейлиста. Истёкшая ссылка обновляется ограниченное число раз; пропуски сохраняются в итоговом отчёте.
- Отказ доступа к отдельной записи отделён от отказа токена аккаунта. Потеря сети, нехватка места и настоящий отказ входа сохраняют очередь для продолжения.
- Перестановки, добавления и удаления других записей библиотеки не сбрасывают готовые проверки дубликатов. Изменившийся трек теряет только собственную проверку.
- Поиск дубликатов заканчивается одним проходом даже при изменении библиотеки: изменившиеся записи исключаются из предложений удаления, автоматического повторного скачивания всей библиотеки нет.
- Удаление каждого дубликата по-прежнему требует отдельного подтверждения и свежей проверки обеих аудиозаписей.

## [0.10.0] — кандидат публичного релиза

- Старый внутренний архив сохраняется и переносится в общую музыку с проверкой размера и SHA-256. Повреждённые записи можно сохранить отдельно.
- Очередь привязана к аккаунту ВК; другая учётная запись не может продолжить её без проверки. Новые данные входа заменяют старые после успешной проверки.
- Перестановка треков и переименование плейлиста не создают повторные копии. Повторяющиеся композиции остаются отдельными позициями.
- Полнота HLS проверяется также по длительности из каталога. Сравнение M4A учитывает конфигурацию декодера и временную шкалу.
- M4A получает текстовые теги, подборки — переносимый M3U8 с порядком и отметкой неполной выгрузки.
- Все ошибки очереди доступны постранично, сохраняются ошибки источников, добавлены адресный повтор и отдельный отчёт результата выгрузки.
- Доступен диагностический журнал предыдущего запуска; из кэша поиска дубликатов удалено ненужное хранение аудио.
- Выпуск stable отделён от push в main: сначала RC, затем приёмка точного APK. Добавлены фиксация зависимостей, SBOM, SCA и публичные доказательства сборки.
- Транзитивная Guava обновлена до 33.7.2-android для исправления GHSA-xxph-c9ww-hj94.
- При переносе старого архива и восстановлении незавершённой записи учитывается окончательное имя, выбранное Android при совпадении файлов. Исходные файлы сохраняются.

Реальный вход/продление ВК, массовая выгрузка и длительная фоновая работа требуют ручной приёмки RC. До её заполнения stable заблокирован.
