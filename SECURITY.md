# Сообщения об уязвимостях

Для проблемы с утечкой токенов, обходом проверки подписи, удалением чужих файлов или доступом к аккаунту используйте [приватное сообщение об уязвимости GitHub](https://github.com/alcovaibe/vk-music-export/security/advisories/new). Если приватный канал недоступен, создайте Issue с просьбой о приватном канале без секретов и без подробностей эксплуатации. Не публикуйте рабочие токены, cookie, APK ключи, коды подтверждения и чужие данные.

Укажите версию/номер сборки, Android/устройство, минимальные шаги, ожидаемый и фактический результат. Диагностический файл отправляйте после просмотра и удаления личных данных. Исправления готовятся для актуальной версии; гарантированный срок реакции и аудит безопасности не обещаются.

Автоматические проверки не заменяют ручную приёмку реального входа, массового скачивания и длительной фоновой работы. Требования к проверке конкретного APK перечислены в [порядке выпуска](CONTRIBUTING.md#выпуск-релиза).
