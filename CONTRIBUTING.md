# Участие в разработке

Создавайте ветку и PR к `main`. Опишите проблему, итоговое поведение и выполненные проверки. Не включайте реальные данные ВК и секреты. Для дефекта сохранности данных добавьте регрессию с синтетическим файлом/ответом. Не удаляйте опубликованную музыку при очистке очереди, кэша или истории.

Нужны JDK 21, SDK 37.0 и build-tools 36.0.0. `python3 -m unittest discover -s tools -p 'test_*.py'`, `./gradlew testDebugUnitTest lintDebug lintRelease assembleDebug assembleRelease` и инструментальные тесты API 36/37 — обязательные проверки. Эмулятор должен быть одноразовым: upgrade-check меняет его данные и отказывается работать с физическим устройством.

Обновления зависимостей сопровождайте проверенными checksum/lock, SBOM/SCA, обновления Actions — полным SHA. Для изменения поведения пользователя обновите документацию и точный раздел CHANGELOG. Порядок выпуска — [RELEASING.md](docs/RELEASING.md).
