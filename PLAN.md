# 0.9.14 — результаты обложек и главное меню

- В нижней панели три отдельных списка: ВК не передал ссылку на обложку, трек недоступен текущему доступу, ошибка обработки/получения картинки. Все строки содержат название и исполнителя; ограничения последними десятью больше нет, список ленивый. Итоги разделены, прежний общий missing остаётся в JSON для совместимости.
- Ошибка получения картинки сохраняет HTTP-статус и фиксированную причину перенаправления. HTTP 404/410 не доказывает отсутствия обложки в ВК; HTTP 401/403 от сервера картинки не доказывает истечения музыкального токена. Небезопасный предложенный адрес больше не выдаётся за отсутствие обложки.
- Экран настроек, копирование в буфер и выбор старых JSON удалены из UI. Меню из трёх точек содержит один пункт отправки свежего отчёта текущего запуска через FileProvider. Внутренний журнал/политика хранения не удаляются.
- Основной фон #000000 независимо от системной светлой/тёмной темы, контрастные цвета и светлые системные значки сохранены. «Музыка ВК» убрано, кнопка называется «VK Music».
- Проверка обновления APK отличает старую кнопку опубликованной 0.9.5 от новой; проверки сертификата, версии, очереди, публичной музыки и старого collection.json сохранены. Новая Python-регрессия отклоняет старую подпись после установки/перезапуска.

SDK, подпись, зависимости, шифрованный доступ, аудиозагрузка и резервное копирование не изменены. Новые причины требуют повторной обработки на устройстве; старые HTTP-ошибки восстановить задним числом невозможно. Реальный HTTP-статус двух картинок владельца пока неизвестен.
