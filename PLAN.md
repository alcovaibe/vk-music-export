# 0.9.9 — отдельные плейлисты и альбомы

Вкладки «Моя музыка», «Плейлисты», «Альбомы» и отдельный список неизвестных типов. Метаданные каталога читаются постранично целиком до фильтрации; UI отображает до 100 подборок выбранного типа. Неполный каталог явно помечается.

Тип определяется по подтверждённым строковым полям ВК; числовой type без подтверждения остаётся неизвестным. Ручной выбор и его сброс сохраняются в meta SQLite с ключом аккаунта и подборки. Явный тип сервера имеет приоритет. Неизвестные типы не превращаются в плейлисты автоматически.

Отдельные очереди для всех плейлистов/всех альбомов и одной подборки. Группы треков «Моей музыки» по альбомам создаются отдельным явным действием и не объявляются полными альбомами. SDK, подпись, авторизация и форматы файлов сохранены. Проверки используют синтетические ответы; реальные числовые типы и массовое скачивание аккаунта ими не подтверждаются.
