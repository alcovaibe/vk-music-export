# 0.9.10 — ручное удаление скачанного трека из «Моей музыки» ВК

Корзина доступна только у трека на странице «Моя музыка» текущего аккаунта. После нажатия проверяются идентичность, сохранённая копия в Music/VK Music Export/Моя музыка, её размер и SHA-256. Отдельная нижняя панель позволяет открыть файл и подтвердить удаление из ВК. Перед отправкой файл проверяется повторно; опубликованные локальные файлы и SQLite-учёт не удаляются.

Используется audio.delete с owner_id текущего аккаунта и audio_id выбранного трека, без playlist_id. Токен отдельно сверяется через users.get. Запрос удаления не проходит через автоматическое переисполнение MusicSessionManager; транспортные повторы отключены. Отказ ВК показывается явно, неоднозначный сетевой результат не объявляется успехом. При подтверждённом удалении страницы перечитываются с нулевого offset.

Контракт подтверждён исходниками SDK, но актуальные права нашего внутреннего музыкального токена и реальное удаление на аккаунте владельца ещё не проверены. В CI только синтетические ответы и настоящие тестовые файлы MediaStore. Авторизация, подпись и SDK сохранены.
