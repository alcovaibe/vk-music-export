# 0.9.4 — публичные обновления и настройки

Версия приложения отображается внизу слева главного экрана. В настройках удалены заголовок «ВКонтакте», дублирующий переход к музыке и прежняя строка версии.

После публикации репозитория обновлятор переведён на публичный JSON-канал в docs/updates/android.json, по схеме Bluetooth Disable. PAT больше не нужен. Сохраняются интервалы проверки, прогресс, отмена, проверка APK и штатная установка Android. Старый зашифрованный PAT удаляется локально; музыкальные доступы не меняются.

Процесс выпуска обновляет канал только после публикации и сверки APK. build-info.json и upgrade-check.txt остаются в артефактах CI. Проверка установки поверх опубликованной 0.9.3 (1080) с прежней подписью обязательна. Существующие релизы не редактируются.

Исправлена регрессия инструментального теста: он больше не нажимает удалённый пункт настроек, а использует кнопку главного экрана. Проверки в текущем PR должны пройти на API 36 и 37. Изменение авторизации/окна Chrome в этот объём не входит.
