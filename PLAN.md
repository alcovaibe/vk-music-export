# 0.9.1 — очистка старого интерфейса

Цель: оставить работающий нативный доступ и скачивание, убрать прежний браузерный сбор и экспорт списков.

- Авторизация: существующий Chrome Custom Tab → подтверждение → музыкальная проверка → зашифрованный доступ.
- Метаданные: VkAudioClient/MusicPagination → показ страницы → подтверждённое CollectionMerge при сохранении.
- Аудио: существующая SQLite-очередь → AudioTransfer/Media3 → MediaStore в Music/VK Music Export.
- NativeOperationJournal отвечает только за владение/восстановление нативных операций.
- LegacyAudioCleanup удаляет только старый внутренний архив и его кэш/индекс; не посещает общую Music, очередь или доступы.
- ChromeDiagnostics сохраняет сведения о браузере без общего запуска сайта.
- Логи JSON и обновлятор остаются отдельными компонентами.

Перед выпуском: JVM/lint/build, Android-проверки входа и кода, сохранения коллекции, очистки, ссылок, Media3/MediaStore/SQLite/UIDT; релизный install -r поверх 0.9.0 (1067), прежняя подпись, сохранение коллекции/диагностики/очереди/Music.

Следующий факт для проверки владельцем: результат массовой загрузки его реальной библиотеки. Один реальный MP3 и новый путь уже подтверждены владельцем. Протокол ВК внутренний; полнота каталогов и автоматическое обновление истёкшего токена не обещаются.
