# 0.9.17 — продолжение проверки дубликатов

- Завершённые проверки сохраняются атомарно в noBackupFilesDir/duplicate-scan. После остановки/перезапуска повторное полное чтение библиотеки разрешает повторное использование SHA-256 только для того же аккаунта и точного снимка.
- Срок 24 часа, до 20 000 результатов; готовые приватные аудиокопии до 256 МиБ. Вытеснение аудио не требует повторной загрузки уже проверенного результата. Частичный трек проверяется заново.
- Исправлен локальный ACCESS после успешного автопродления в длительном поиске. Чтение следует только проверенной цепочке продлений; новый вход/выход прерывает старую операцию. Итог связан с актуальным доступом.
- Перед мутацией кэш не используется: свежая загрузка обеих записей, проверка библиотеки, точного credential_id, одноразовое отдельное согласие, без автоматического повтора audio.delete.
- Нижняя панель: продолжение, сохранённые/повторно использованные проверки. JSON: фиксированный этап, vk_code и счётчики без имён, ID треков, URL или секретов. Скриншот не устанавливает причину конкретной прошлой остановки.
- Новые JVM/инструментальные проверки синтетические; реальное продолжение и удаление не подтверждены. SDK, зависимости и подпись прежние. Канал обновления меняется только после выпуска настоящего APK.

# 0.9.16 — ручной поиск обложки после удаления записи из библиотеки ВК

- У результата «Не найдены по сохранённому ID» отдельная кнопка поиска. Обрабатывается конкретный сохранённый файл, а не догадка по имени файла.
- В нижней панели поиск по исполнителю/названию или полная ссылка ВК, страницы по 20 до первых 100 вариантов, название/исполнитель/длительность/альбом, ручной просмотр и отдельное подтверждение картинки. Обычное чтение библиотеки/подборок остаётся по 100.
- Варианты изображений берутся из самого ответа поиска/ссылки. Повторно не запрашивается старый недоступный ID. Сохраняются перебор 404/410 и прежние проверки/лимиты CDN.
- Старые NativeTrack/ID, аудиоданные, имя, папка, URI и очищенная история сохраняются. Используется прежний ArtworkRepair и журнал. Перед записью дополнительная проверка активности приложения, поколения операции и доступа.
- Выбор одноразовый, срок 5 минут; результаты 10 минут. Выход, фон, смена доступа, другой запрос или другая операция сбрасывают выбор. URL/запросы/имена/ID/картинки/секреты не пишутся в журнал.
- Реальная попытка владельца на 0.9.15 подтвердила две добавленные обложки с размером 300 и одну успешную попытку продления доступа. Это не подтверждение нового поиска: его реальная работа и права ВК ещё требуют проверки.
- SDK 36/36/37, подпись и зависимости сохраняются. Публичный канал меняется только после настоящего проверенного релиза. Подробности: [поиск](docs/ARTWORK-LOOKUP.md), [обложки](docs/ARTWORK.md).
