# 0.9.5 — удаление локальной коллекции

Удаляются экран локальной коллекции, сохранение страницы, кнопка очистки и весь обслуживающий код. Главный экран сохраняет вход в музыкальный раздел, настройки и версию внизу слева.

Авторизация, музыкальный API, постоянная очередь, UIDT и сохранение в Music/VK Music Export не меняются. Старый collection.json остаётся на месте, но больше не читается и не изменяется. Проверки на API 36/37 должны подтвердить навигацию и прежнюю работу очереди и авторизации, включая запуск при повреждённом старом файле коллекции.

Подписанное обновление в main-релизе проверяется поверх опубликованной 0.9.4 (1085). Проверяется новый главный экран, неизменность старого файла, публичной музыки, приостановленной очереди и журналов. Публичный канал обновляется только после публикации и проверки APK.
