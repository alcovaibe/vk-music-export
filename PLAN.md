# 0.9.2 — обычные имена файлов и папок

Запрос владельца: убрать номер композиции перед именем и служебные ID после названий треков, плейлистов и альбомов. Новый формат: `Исполнитель — Песня.mp3` и `Плейлисты/Солнечный день/`.

Внутренние ключи и позиции прежние. Добавляется приватная таблица соответствия источников и видимых каталогов, с короткими суффиксами при совпадениях. MediaStore публикует новый файл под свободным именем. Уже опубликованные файлы не перемещаются и не переименовываются; совместимость очереди/контрольных точек сохраняется.

Проверки: Unicode/подлинные скобки в названии, повторы, одинаковые названия разных источников, восстановление соответствий, миграция схемы v1 и переиспользование старых URI без сети. Существующий CI проверяет JVM/lint/Android 16 и подписанный install -r поверх опубликованной 0.9.1 (1070), с прежним сертификатом и данными.

Рабочий вход через Chrome, API, передача/проверка аудио, очередь, диагностика, коллекция и обновлятор сохраняются. Полный массовый прогон реальной библиотеки не подменяется CI-фикстурами.
