# 0.9.8 — скачивание в нижней панели

Прогресс и управление очередью вынесены в общую нижнюю Compose-панель. Кнопки открытия находятся на главном экране и в верхней панели музыкального раздела. При запуске/продолжении/повторе скачивания панель открывается автоматически; закрытие не останавливает UIDT.

Показываются общий прогресс, текущий трек, объём полученных данных, известные сегменты HLS, итог и пропуски. Сохранены пауза, продолжение, повтор и очистка очереди с сохранением файлов. Текущая задача берётся из SQLite без миграции схемы.

Проверки: управление/сворачивание/повторное открытие панели, обе точки входа, пересоздание Activity, автоматическое открытие и завершение настоящей UIDT-задачи с синтетическим недоступным треком без аккаунта и запросов к музыкальному API ВК. Полная проверка реальной массовой загрузки и продления доступа владельцем остаётся отдельной.
