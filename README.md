# VK Music Export

Android-приложение с публичным исходным кодом для сохранения музыки из своей библиотеки ВК на устройство. Поддерживает отдельные треки, плейлисты и альбомы, фоновое скачивание, встроенные обложки и поиск дубликатов.

**Требуется Android 16 или новее.** [Скачать APK](https://github.com/alcovaibe/vk-music-export/releases)

## Начало работы

1. Установите APK из [раздела Releases](https://github.com/alcovaibe/vk-music-export/releases).
2. Подключите аккаунт кнопкой **VK Music**.
3. Откройте библиотеку и выберите музыку для скачивания.
4. Разрешите уведомления для отображения фонового прогресса и управления загрузкой.
5. Сохранённые файлы появятся в `Music/VK Music Export`.

## Возможности

### Музыкальная библиотека

- Просмотр «Моей музыки», плейлистов и альбомов в отдельных разделах.
- Скачивание отдельных треков, выбранных подборок или всей доступной библиотеки.
- Все треки библиотеки и открытой подборки, а также все плейлисты и альбомы доступны в одном прокручиваемом списке без переходов по 100 позиций. Страницы ВК загружаются автоматически с показом прогресса; строки создаются по мере прокрутки.
- Автоматическое разделение плейлистов и альбомов по серверному фильтру ВК. Старые ручные назначения типа не применяются. Если сервер не поддерживает определение типа, подборка доступна в общем разделе без ручного выбора.
- Полностью скачанные подборки скрываются после сверки текущего состава, аккаунта, целостности аудиофайлов и M3U8. Частичная загрузка, новый трек, отсутствующий или изменённый файл возвращают подборку в список. Удалённые из каталога ВК подборки не добавляются из локальной истории.

Каталог читается страницами; при неполном ответе приложение показывает проблему, а не объявляет библиотеку полной. Повторяющиеся позиции каталога не создают дубли и не превращают полный ответ в ошибочно неполный. Обновление заменяет прежний список и закрывает выбранный источник; при ошибке старые подборки не показываются как актуальные. Каталог обновляется при входе в музыкальный экран, возвращении в приложение и завершении очереди.

Группы альбомов, сформированные из «Моей музыки», содержат только сохранённые в библиотеке композиции и могут отличаться от полного альбома.

### Скачивание

- Фоновая загрузка с прогрессом и управлением через уведомление.
- Кнопка скачиваний вверху экрана «Доступ к музыке» открывает нижнюю панель с текущим треком, объёмом полученных данных, состоянием очереди и пропусками.
- Пауза, продолжение после перезапуска приложения и повтор неудачных загрузок.
- Проверка готовых файлов и повторное использование подходящей локальной копии. Перестановка треков и переименование подборки сохраняют связь с файлом.
- Одна проверенная копия трека с тем же ID ВК используется сразу в нескольких подборках. Повторяющиеся позиции сохраняются в M3U8 без размножения MP3/M4A. Сам файл остаётся в первой папке сохранения; остальные подборки ссылаются на него относительным путём.
- Очередь привязана к проверенному аккаунту ВК; другой аккаунт не может продолжить её.
- Все ошибки доступны постранично; отдельные источники можно повторить без сброса готовых файлов.
- При несовпадении длительности показаны ожидаемое и полученное время; для недоступных записей — причина отказа или HTTP-статус, если они известны. Эти подробности включаются в отчёт результата.
- Сохранение MP3 в MP3 и AAC в M4A без перекодирования, с текстовыми тегами.
- Файл `_Порядок.m3u8` в каждой подборке сохраняет порядок, повторы и отмечает неполную выгрузку. Поддержка относительных M3U8 зависит от проигрывателя.

Музыка сохраняется в общую папку `Music/VK Music Export`:

- `Моя музыка/Исполнитель — Название.mp3`
- `Плейлисты/Название плейлиста/…`
- `Альбомы/Название альбома/…`

Уже накопленные копии и файлы других приложений автоматически не удаляются и не объединяются по названию. Одинаковые названия могут относиться к разным версиям записи. Проверка длительности и целостности сохраняется даже при совпадении ID.

Если при восстановлении выбран отличающийся файл, он остаётся локальной заменой с отдельной отметкой в истории и отчёте. Такая замена не используется как подтверждение сохранённого оригинала при удалении песни из ВК.

Старый внутренний архив автоматически переносится в «Восстановленные/Из старой версии» с проверкой размера и SHA-256; оригиналы сохраняются. Для повреждённого индекса и неперенесённых файлов есть ручное сохранение копии.

Имена файлов состоят из исполнителя и названия. При совпадениях добавляется суффикс; одноимённые подборки получают отдельные папки. Ранее сохранённые файлы не переименовываются автоматически.

Файлы доступны другим приложениям и остаются на устройстве после удаления VK Music Export. Очистка списка последних сохранений удаляет только историю отображения.

Недоступный трек не останавливает скачивание остальных. После ограниченных повторов ошибки отдельных аудиофайлов сохраняются в списке пропусков и итоговом отчёте.

«Повторить ошибки» проверяет сохранённые файлы на телефоне и повторяет только неудавшиеся записи и отсутствующие/изменённые копии. Повторный выбор того же плейлиста не скачивает готовые треки заново. Проверка больших файлов может занять время; в прогрессе показан этап проверки сохранённого.

Если файлы перемещены, приложение ищет точное совпадение размера и SHA-256 среди доступных ему собственных файлов в Music. Это работает также для известной копии из альбома, перенесённой в папку плейлиста с заменой. По одному названию файл не пропускается. Если Android сменил владельца файла, нет доступа или найдено несколько одинаковых копий, используйте «Проверку сохранённых файлов» и явный выбор файла. Приложение не удаляет и не перезаписывает изменённые пользователем файлы.

Если загрузка не завершилась, откройте панель скачиваний и просмотрите ошибки. Можно повторить неудачные задачи или перечитать конкретный источник. Ошибка доступа, смена аккаунта или проблема накопителя могут поставить очередь на паузу. Сворачивание панели само по себе скачивание не останавливает.

### Обложки

- Встраивание обложек в новые MP3 и M4A.
- Добавление обложек к ранее скачанным файлам, которые учитываются приложением.
- Повтор обработки неудачных записей с пропуском уже готовых.
- Перебор доступных размеров картинки, если ВК вернул неработающую ссылку.
- Ручной поиск обложки по названию и исполнителю либо полной ссылке на песню ВК.
- Предпросмотр выбранной картинки и отдельное подтверждение её встраивания.

Для записи без доступной обложки откройте ручной поиск, уточните исполнителя и название или вставьте полную HTTPS-ссылку на песню ВК. Выберите вариант, просмотрите картинку и подтвердите её добавление. Совпадение названий не доказывает совпадение исполнения; найденная запись используется только как источник изображения. Короткие ссылки и произвольные адреса картинок не поддерживаются. Поиск зависит от прав доступа ВК.

Ручной выбор сбрасывается при закрытии панели, уходе в фон или смене доступа. Существующая обложка не заменяется. Если при новой загрузке картинка недоступна, проверенный аудиофайл сохраняется без неё.

При изменении обложки аудиоданные сохраняются без перекодирования. Перед обработкой существующего файла проверяется его целостность, создаются резервная копия и журнал восстановления.

### Поиск дубликатов

Приложение находит кандидатов по названию и исполнителю, затем временно скачивает их и сравнивает аудиоданные без текстовых тегов и обложек. Полные аудиокопии после проверки не сохраняются в постоянном кэше.

- Поиск продолжается в фоне после сворачивания приложения; уведомление показывает этап и прогресс и позволяет поставить проверку на паузу.
- Завершённые проверки сохраняются на 24 часа.
- Прерванный поиск можно продолжить без повторной загрузки уже проверенных треков, для того же аккаунта. Изменение порядка или другой записи не сбрасывает проверки неизменившихся треков.
- Каждая лишняя запись удаляется из библиотеки ВК только после отдельного подтверждения.
- Перед удалением обе записи повторно загружаются и проверяются.
- Локальные музыкальные файлы при этом сохраняются.

Откройте «Очистить дубликаты» в разделе своей библиотеки и запустите проверку. Кнопка «Дубликаты: процесс и результат» возвращает к свёрнутой панели. После остановки используйте «Продолжить проверку»: подходящие готовые проверки используются повторно только для того же аккаунта и неизменившейся библиотеки. Поиск выполняет один проход. Если библиотека изменилась во время проверки, результат формируется для сохранившихся неизменённых записей; новые и изменённые можно проверить отдельным запуском. Автоматического перезапуска скачивания всей библиотеки нет. Подтверждения удаления между запусками не сохраняются.

Поиск и скачивание музыки не выполняются одновременно. Удаление дубликата требует активного приложения и свежей проверки обеих записей. Доступно также отдельное удаление скачанного трека из «Моей музыки» ВК: оно подтверждается отдельно, а локальный файл остаётся.

Сравнение побайтовое: разные битрейты, кодеки и версии исполнения могут не считаться дубликатами.

### Доступность треков

Отдельная панель позволяет повторно проверить недоступные записи из библиотеки, очереди и результатов поиска дубликатов. Приложение различает явное ограничение ВК, пустой ответ, отсутствие ссылки и другие причины отказа.

Перед скачиванием запрашиваются свежие данные точного трека: старая отметка ограничения не мешает использовать новый разрешённый ответ. Доступ определяется текущим аккаунтом и соединением; иностранный регион сам по себе не гарантирует доступность композиции.

### Восстановление файлов

Если сохранённый файл переместили или переименовали, приложение помогает восстановить связь с ним:

- Автоматически ищет единственное совпадение размера и SHA-256 среди доступных файлов приложения.
- Позволяет вручную выбрать аудиофайл и после подтверждения создать собственную копию.
- Показывает причины отказов проверки.
- Позволяет убрать устаревшую запись из учёта без удаления самого файла.

## Вход и данные доступа

Вход открывает страницу ВК через Chrome Custom Tab. Если ВК запросит код подтверждения, следуйте подсказкам на экране. Пароль и подтверждение аккаунта вводятся на стороне ВК. Приложение не читает профиль и cookies Chrome.

Полученный доступ проверяется до сохранения. Данные доступа и материал его продления хранятся зашифрованно с использованием Android Keystore. Если ВК сообщил срок, приложение показывает его и пытается продлить доступ перед истечением или после отказа музыкального запроса. Автоматическое продление не гарантируется; при отказе нужен повторный вход. Неизвестный срок не заменяется выдуманным временем действия.

Ручной ввод уже полученного музыкального токена доступен через «Настроить доступ ВК», пока доступ не подключён. Для повторного подключения используется Chrome. Ручной токен сам по себе не даёт возможности автоматического продления. Не отправляйте токены и коды входа в Issues или диагностических сообщениях.

При смене аккаунта прежняя очередь не продолжается от имени другого пользователя. Для старой очереди без привязки требуется явное подтверждение аккаунта.

## Обновление приложения

Кнопка с двумя стрелками на главном экране открывает проверку обновлений, скачивание и установку. Приложение обращается к публичному каналу GitHub; GitHub-токен не требуется. Автоматическая проверка выполняется раз в сутки, скачивание запускает пользователь.

Перед установкой проверяются размер и SHA-256 APK, идентификатор приложения, версия, требования Android и подпись. Установку подтверждает Android. После выдачи разрешения устанавливать приложения из этого источника вернитесь в VK Music Export и снова нажмите «Установить».

«Позже» откладывает предложение конкретной версии. Отмена скачивания удаляет неполный APK. Для сохранения данных устанавливайте обновление поверх приложения без предварительного удаления.

## Диагностика и отчёты

Меню трёх точек на главном экране открывает «Данные и доступ» и «Лицензия» в нижних панелях с прокруткой; документы доступны без сети и входа в ВК. Там же можно поделиться JSON-отчётом текущего запуска. Если сохранён предыдущий запуск, для него доступен отдельный отчёт. Журналы ограничены по объёму и содержат этапы, счётчики и коды ошибок без токенов, cookies и подписанных ссылок. После аварийной остановки последние ещё не записанные события могут отсутствовать.

В панели скачиваний есть отдельный полный отчёт результата выгрузки. Он содержит названия песен, account ID, статусы и относительные пути файлов. Это не обезличенный журнал: просмотрите его перед отправкой.

Для обращения об ошибке укажите версию и номер сборки, модель устройства, Android, шаги воспроизведения, ожидаемый и фактический результат. Отчёт отправляется только по вашему действию через системное меню «Поделиться».

## Очистка данных

| Действие | Что происходит |
| --- | --- |
| Очистить очередь | Удаляется состояние очереди; сохранённые музыкальные файлы остаются |
| Очистить «Последние сохранения» | Очищается отображаемая история; файлы и учёт скачанного остаются |
| Убрать устаревшую запись файла | Удаляется запись из учёта, сам файл не удаляется |
| Удалить данные доступа ВК | Удаляются локальные данные входа и кэш проверки дубликатов; музыка остаётся |
| Удалить трек из библиотеки ВК | После подтверждения изменяется библиотека ВК; локальный файл остаётся |
| Удалить приложение | Удаляются приватные данные приложения; общая папка с музыкой остаётся |

Удаление локальных данных доступа не завершает сессию Chrome и не отзывает доступ на стороне ВК. Для серверного отзыва используйте настройки сеансов и приложений своего аккаунта ВК. Перед удалением приложения отдельно сохраните неперенесённые файлы старого внутреннего архива.

## Ограничения

Доступность музыки, обложек, поиска и удаления записей зависит от ответа ВК и прав текущего аккаунта. Удалённые и недоступные композиции могут не скачиваться.

После прерывания сохраняется состояние очереди, но незавершённый трек загружается заново. Продолжение после перезапуска запускается пользователем.

Поддерживаются VOD-потоки MP3/AAC. Лимита 100 МиБ и общего десятиминутного срока загрузки нет; большие записи сохраняются потоком. Нужен запас места для временного файла, обработки и публикации. Неактивное соединение прерывается по сетевому тайм-ауту. Для HLS действуют структурные пределы: до 20 000 сегментов, список до 8 МиБ, отдельный сегмент до 16 МиБ. Другие аудиоформаты могут не поддерживаться. Проверка соответствия длительности каталогу остаётся обязательной.

Поиск дубликатов требует времени, трафика и свободного места. Android может остановить фоновую задачу; готовые проверки сохраняются для продолжения.

Используется внутренний музыкальный протокол ВК. Его изменения могут потребовать обновления приложения. Автоматические тесты проверяют работу на синтетических ответах и локальных аудиофайлах; доступность конкретной музыки на реальном аккаунте определяется сервером ВК.
