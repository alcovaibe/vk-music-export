# VK Music Export

Приватный проект Android-утилиты для экспорта названий треков, исполнителей и структуры музыкальной коллекции ВК.

**Статус:** подготовлен план реализации. Android-код и APK пока не созданы; вход и полнота получения коллекции на устройстве ещё не проверены.

## Планируемые возможности

- Сбор доступной «Моей музыки» и созданных/сохранённых плейлистов.
- Сохранение порядка и повторов внутри плейлистов.
- Общий список уникальных аудиозаписей.
- Локальный экспорт TXT, CSV, JSON и ZIP.
- Прогресс, продолжение после остановки и явный отчёт о полноте.

## Разработка

Подробные этапы, технические решения и критерии готовности: [PLAN.md](PLAN.md).
